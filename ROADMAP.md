# Ravi Roadmap

## v0.1.x (current)

- [x] Standalone repository & MIT license
- [x] Docker Compose with Ravi-prefixed services and volumes
- [x] Cloudflare message transformation patch
- [x] CLI for lifecycle management and basic testing
- [x] Multi-key Gemini load-balancing configuration

## v0.2

- [ ] First-class Ollama / local model support documentation and sample config
- [ ] Simple web status / model browser (optional, non-admin)
- [ ] Health & metrics exporter (Prometheus-friendly)
- [ ] Better configuration validation on `ravi start`

## v0.3+

- [ ] Plugin / integration interface for additional providers
- [ ] Optional vector-store / memory connectors
- [ ] Multi-instance / HA deployment notes
- [ ] Official client SDKs or thin wrappers if needed

Feedback and contributions welcome — see [CONTRIBUTING.md](CONTRIBUTING.md).
