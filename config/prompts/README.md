# Response templates

Edit these files to customize how Ravi shapes outputs:

| File | Used when |
|------|-----------|
| `text.md` | Every chat completion |
| `voice.md` | Voice is ON (TTS wording) |
| `image.md` | Image generation requests |
| `video.md` | Video generation requests |

Ravi loads them at runtime. No restart required for the next request.
